# LineBundle SDKs

Auto-generated SDKs for the LineBundle API, published via Speakeasy on every release.

## SDKs

- [`sdks/typescript`](./sdks/typescript) — TypeScript SDK
- [`sdks/python`](./sdks/python) — Python SDK

> These SDKs are automatically generated and versioned by the LineBundle CI pipeline on every `v*` release tag.
