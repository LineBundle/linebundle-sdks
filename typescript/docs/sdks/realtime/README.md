# Realtime

## Overview

* [realtimeInfoRealtimeInfoGet](#realtimeinforealtimeinfoget) - Realtime WebSocket protocol info
* [getWs](#getws) - Establish realtime WebSocket connection (upgrade)

## realtimeInfoRealtimeInfoGet

Get WebSocket protocol information.

Returns documentation about the WebSocket endpoint including:
- Connection endpoint
- Authentication requirements
- Protocol details
- ACK message format

Returns:
    dict: WebSocket protocol information
